Complete User Guide & FAQs

Detailed operating instructions for administrators, class teachers, and proxy teachers.

1. Operating User Roles

  • 👑 Admin: Log in using Admin credentials. Admins can configure school details, manage classes, update class teacher names, reorder class sequences, configure holidays, and view school-wide reports.
  • 👨‍🏫 Class Teacher: Select your specific class from the dropdown and log in with your class password. You can manage student records (with G.R. No. and Roll Nos), mark monthly attendance, assign proxy teachers, and download class reports.
  • 👤 Proxy Teacher: Log in using credentials set up by your class teacher. Proxy teachers can only mark or edit attendance for the current calendar date.

2. Managing Student Data & Excel Imports

When adding a student, enter their unique G.R. No. (General Register Number) and mandatory fields. You can also import students in bulk using an Excel template downloaded from the Student Data tab.

If a student leaves the school, click Left and provide the leaving date. Roll numbers adjust automatically.

3. Frequently Asked Questions (FAQs)

Q: Can proxy teachers edit past attendance?

A: No. Proxy teachers are restricted strictly to marking attendance for the current calendar date.

Q: How do dual school logos appear on reports?

A: Upload your left logo and right logo in the "School & Sessions" tab. They will automatically be embedded on all printed or downloaded PDF/Excel reports.
